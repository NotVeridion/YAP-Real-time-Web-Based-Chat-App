# YAP-Real-time-Web-Based-Chat-App
A simple chat application capable of real-time text communication, personal room creation for group messaging, and personal chat customizations

Visit https://yapchatapp.com/ to try it out!

### How to Run in Your Local Machine (In case deployment fails)
1. Extract repository as a zip file
2. Open project folder
3. Open your terminal and run the following commands:
```
pip install -r requirements.txt
python app.py
```
4. Visit http://127.0.0.1:5000/ on your browser
