# YAP-Real-time-Web-Based-Chat-App
A simple chat application capable of real-time text communication, personal room creation for group messaging, and personal chat customizations

How to Run in Your Local Machine
    1- "cd" to the repository that the code is stored at
    2- "pip install -r requirements.txt" to have the code running properly
    3- "python app.py" to run in your local machine

Ways of testing and using the website: http://127.0.0.1:5000/

How to Use the Website First User (creating room)
    1- Input your username
    2- Input your room code
    3- Click create room
You are now in the web chat
    4- Change colors
    5- Text and see your message go

How to Use the Website Second User (can be repeated mutliple times)
    1- Input your username
    2- Input the room code from the first user
    3- Click join room
You are now in the web chat
    4- Change colors
    5- Text and see the messages from the first user

Ways on How to Not Use the Website (will give error message nicely)
    1- No username
    2- No room code
    3- Wrong room code
